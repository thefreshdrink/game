# Карта документов Tarot Journey

Что где лежит и зачем. Сверено с файлами 2026-10-17.

**Правило одно:** всё, что считается правдой о проекте, живёт в этой папке
(`tarot-journey/`). Папка выше (`game/`) — архив старого прототипа и
исходников: оттуда можно брать картинки и идеи, но не правила.

---

## Пять документов, которые стоит знать

| документ | простыми словами | когда открывать |
|---|---|---|
| `docs/vision.md` | **зачем игра**: что это, для кого, что нельзя менять | когда сомневаешься в направлении |
| `docs/open-questions.md` | **что ещё не решено** и где код расходится с задумкой | перед любым решением |
| `docs/decisions-log.md` | **что уже решили и почему**, свежее сверху | чтобы не решать второй раз |
| `docs/tarot-gdd-v2.md` | **как устроена игра**: экраны, карты, мини-игры | когда нужна подробность |
| `docs/art-recipe.md` | **как делать арт**: какой инструмент, какой размер, сколько стоит | перед каждой генерацией |

План работ по неделям до MVP — `docs/roadmap.md`.

## Если документы спорят

Сверху важнее:

1. последнее задание `BUILD-SPEC-0N.md`
2. `docs/vision.md`
3. `docs/decisions-log.md`
4. `docs/tarot-gdd-v2.md`
5. `docs/roadmap.md`
6. `docs/interfaces/*.png`
7. `docs/design-system.md`
8. `ASSETS.md`

Код говорит правду только о том, что сделано сейчас, а не о том, как должно
быть. Нашёл противоречие — скажи вслух.

## Порядок

- Решение принято — запись в `decisions-log.md` в тот же день.
- Вопрос закрыт — убрать из `open-questions.md`.
- Плейтест — в `docs/reviews/` с датой.
- Один документ живёт в одном месте, копий не делаем.
