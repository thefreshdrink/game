# Рецепт арта: новая карта за 3–4 часа

Один рецепт вместо трёх документов. Справочник по сервису (все инструменты,
права, ключи) остаётся в `pixellab.md`; объяснение для человека, как править
руками, — в `pixel-assets-howto.md`; разбор сессии с бруском — в
`pixel-asset-pipeline.md`. **Как делать — здесь.**

Пометки: **[проверено]** — так сделан ассет, который сейчас в игре (коммит
указан). **[гипотеза]** — не пробовали, это вывод из описания инструмента.
Цены — из описаний инструментов на сервере PixelLab на 2026-10-15; они
изменились с сентября (Pro и состояния подешевели до 10–25).

---

## 0. Перед любой генерацией

1. **Спека в три строки**: экранный размер → зерно → арт-размер; роли тонов
   (тело, верхушка, контур, акцент); что плоское, что с деталью.
2. **Цена и остаток вслух** (`get_balance`). Черновики — только pixflux или
   pixen (1 генерация). Инструмент за 10+ — только после «да».
3. **Референс от человека первым**, если он есть: из него читаются зерно,
   плоскость граней, контраст.
4. Результат **скачать сразу**: PixelLab хранит его 8 часов.

## 1. Зерно и холст — считать, не подбирать

Холст генерации считается от экранного размера:
`арт-размер = экранный размер / зерно`.

| слой | зерно (экранных px на арт-px) | решение |
|---|---|---|
| портрет карты `*_on_the_card.png` | **4** | 2026-09-28, держит `check-asset.py` |
| мини-игра Шута, Башня | **2** | 2026-09-28 (Башня), Шут — по факту |
| будущие мини-игры | не решено | спросить при первой сцене |
| рамка, рубашка карты | 2 | оболочка карты, не портрет |

Окно портрета на лице карты — 188×212 экранных, значит фигура не больше
**47×53 арт-px**. Нынешние портреты: 38–44 арт-px в ширину.

Детализацией правит размер холста, а не слова промпта: на лишнем холсте
генератор кладёт шум. [проверено: бруски Башни, 18–19.09]

## 2. Инструмент по типу ассета

| ассет | инструмент | цена | холст | ключи | статус |
|---|---|---|---|---|---|
| **портрет карты** | `create_character_state` от персонажа Шута `209fab67-fac1-4a68-9705-6dab1cd85697` | 10–25 | 88×88 (как у источника) | `use_color_palette_from_reference: true`, `seed` записать | [проверено: Маг, Колесо `15e5df0`; Императрица `7e8a857`, seed 9061; Башня `83a0c00`, seed 2024] |
| черновик портрета | `create_image_pixflux` | 1 | 42×46 | `view: side`, `outline: single color outline`, `shading: flat shading`, `detail: low detail`, `no_background: true`, `color_image` = полоса палитры | [проверено частично: черновики Отшельника и Звезды 28.09 в галерее; в игру не ставились] |
| **фон сцены** | `create_image_pixen` | 1 | экран / зерно ×2 (400×640 для зерна 2: Pixen рисует пиксель 2×2) | `no_background: false`; промпт по признакам референса | [проверено: фон Шута `5390714`] |
| **тайлы, бруски** (что тайлится) | скрипт, без генерации: `iso-block.py --draw` / `--ref-set` | 0 | по сетке | геометрию считает скрипт, генератор даёт только фактуру | [проверено: кладка Башни] |
| тайлсет платформера | `create_sidescroller_tileset` | 2–3 | тайл 16 или 32 | `shading: flat`, `outline: single color outline` | [гипотеза: не пробовали; дорога Шута сделана раньше другим путём] |
| **предмет** (корона, крепость) | `create_image_pixflux` | 1 | экран / зерно | `no_background: true`, `isometric` для Башни | [проверено: крепость `ec6a8df`] |
| набор мелочи (облака, камни) | `create_image_pro` листом → `cut-sprites.py` | 10–25 | ≤32 px → 64 варианта, 51–64 px → 16 | `style_image` = ассет из игры | [проверено: облака `b22ff4d`] |
| то же с палитрой | `create_image_pro` с `palette` = 14 hex из `tools/palette.py` | 10–25 | как выше | цвета приходят уже наши | [гипотеза: параметр новый, снимает снап] |
| **анимация** | `animate_image` от готового кадра | ~1 за 64×64×8 кадров | кадр ≤256, w×h×кадров ≤ 524288 | `frame_count` чётный, 4 — дыхание, 8 — ходьба | [гипотеза: не пробовали. Ходьба Шута 44×48×8 по описанию ≈1 генерация, а не «20–40», как считали в сентябре] |

**Ракурс сбоку** у портретов не берётся словами «strict side view». Работает
описание через анатомию: «лицо в профиль, один глаз и линия носа, одно плечо
перед другим». [проверено: Императрица, 8 заходов]

**Стиль ссылкой на образец не держится**: образец передаёт палитру и
плотность, но не почерк. Единство дают одно зерно, один источник (персонаж
Шута для портретов), одна палитра и одинаковая доводка. [проверено]

**Сид** — для повторяемости кадра, не для единства стиля: общий сид при разных
промптах стиль не держит (decisions-log 2026-09-28). Понравившийся сид
записывать в коммит. Одно зерно на колоду или своё у карты — B8, см.
`open-questions.md`.

## 3. Палитра в генерацию

Один источник — `tools/palette.py`. Полоса цветов для `color_image`:

    python3 tools/palette.py --strip /tmp/palette.png

Для Pro — тот же список hex: `python3 tools/palette.py --hex`.

## 4. Локальная доводка (бесплатно)

| шаг | скрипт | что делает |
|---|---|---|
| портрет целиком | `tools/new-card.py <id> <png>` | снять апскейл, альфа 0/255, снап в палитру, кроп, чётные размеры, ×4, проверка, файл в `public/assets/card/` |
| посадка на сетку | `tools/pixel-grid.py вход выход --grain auto` | клетка → главный цвет, снап в палитру |
| цветной фон в наши тоны | `tools/pixel-grid.py … --grain 1 --ramp 111111,…,2E2E2E` | тоны по яркости равными долями площади |
| лист → спрайты | `tools/cut-sprites.py лист префикс --min 40` | связные фигуры по файлам, перекраска тонов |
| изометрия 2:1 | `tools/iso-block.py --unit 16 --row 16 --ref-set DIR` | силуэт арифметикой, тона рампой |
| приёмка | `tools/check-asset.py файл.png` | палитра, альфа, чётность, апскейл, зерно портрета |

Ассет, не прошедший `check-asset.py`, человеку не показывается.

## 5. Показ

Контактный лист: вариант крупно + он же в сборке (на лице карты, в кладке
3–5 рядов, на сцене). Выбор — номером, один раз.

## 6. Портрет новой карты по шагам

1. Черновик композиции: pixflux 42×46 с полосой палитры — 1 генерация за
   заход, сколько нужно.
2. Финал: `create_character_state` от Шута с описанием композиции черновика,
   10–25 генераций, только после «да».
3. Скачать PNG, затем `python3 tools/new-card.py <id> скачанный.png` —
   файл ложится в `public/assets/card/<id>_on_the_card.png`, проверка пройдена.
4. Запись в `cards.js` (тексты пишет Алиса) и строка в `ASSETS.md`.
