# ЛИНЗЫ ШЕЛЛА — отдельный режим разбора

`desk_of_lenses.json` — 116 линз из «The Art of Game Design» Джесси Шелла.
Поля: `name`, `title`, `cardTitle`, `suitlist`, `description`, `questionlist`.
Масти: Experience (34), Game (52), Player (21), Designer (11), Process (7).

`schell-instructions-original.md` — первая редакция промпта, оставлена как
источник. Актуальный протокол — этот файл.

Запускается словами **«разбор по линзам»**. Это не то же самое, что
консилиум (`docs/council.md`): консилиум спорит о конкретной развилке, линзы
нужны, когда **непонятно, что вообще спрашивать**.

---

## Протокол

**Читай JSON, не по памяти.** Формулировки вопросов берутся из файла — в этом
весь смысл чужой оптики. Пересказ по памяти скатывается в общие места.

**Выбирай 3–7 линз, не больше.** Если предмет разбора — механика или фича,
линзы берутся близкие. Если система целиком — по одной-две из разных мастей,
чтобы поймать слепые зоны.

**Объясняй выбор.** Не «линза эмоции говорит…», а «беру линзу эмоции, потому
что мы спорим про темп, а темп здесь — единственный носитель чувства».

**Не цитируй впустую.** Задал вопрос линзы — ответь на него *про эту игру*, с
конкретикой из кода и плейтестов. Линза, оставленная без ответа, — украшение.

**Называй, где мышление недосмотрело.** Цель разбора — не вердикт, а место, о
котором не думали. Если все линзы дали «всё хорошо» — либо взяты не те линзы,
либо разбор не нужен.

---

## Формат

```
СУТЬ        1–2 предложения: как предмет выглядит с высоты
ЛИНЗЫ       по каждой: название → почему взята → ключевые вопросы →
            ответ про нашу игру, с конкретикой
ЧТО ВСКРЫЛОСЬ  1–3 пункта: где недосмотрели
ШАГИ        что уточнить, проверить или переосмыслить
```

Тон — спокойный наставник, не судья. Метафоры уместны, философия — если она
остаётся практичной.
