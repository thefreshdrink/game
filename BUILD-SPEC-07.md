# BUILD-SPEC-07 — автоматизация: каркас мини-игры и арт-конвейер

Седьмое задание. Правила проекта — `CLAUDE.md`. Замысел — `docs/vision.md`,
стратегия и приоритет — `docs/roadmap.md`.

**Зачем это задание.** Горизонт продукта — 78 карт, ресурс — 7 часов в неделю.
Единственная метрика, которая это связывает, — стоимость новой карты в часах.
Сейчас ~15–20, цель — 3–4. Это задание снимает три из четырёх слагаемых:
копирование кода мини-игры, отбор кадра генератора и ручное сведение стиля.

**Что считается готовым:** новая карта заводится одной командой и одним файлом
сцены; ни один ассет не правится руками после генератора; проверка стиля
проходит автоматически.

**Открытые решения** помечены `РЕШИТЬ` — не додумывать, спросить.

## Задача 1. Вынести каркас мини-игры из `leap.js`

`leap.js` — 1235 строк при правиле «файл больше ~400 строк — повод разделить».
Внутри лежит всё сразу: физика, камера, подсказки, знаки жестов, кат-сцена
падения, сцена прибытия, рендер дороги. Четыре оставшиеся карты не могут это
переиспользовать — только скопировать.

Вынести в `src/core/`:

| модуль | что забирает |
|---|---|
| `minigame.js` | жизненный цикл `init / update / render / onInput`, общий для всех карт; вход и выход сцены, склейка с экраном предсказания |
| `camera.js` | следование за героем, клэмпы, пересчёт world → screen |
| `juice.js` | частицы, пыль, дрожь кадра, замедление времени, вспышки, эмиттер |
| `hints.js` | подсказки столбиком у фигуры с клэмпом по стейджу, логика показа и снятия |

В `src/minigames/fool/` остаётся только то, что принадлежит Шуту: профиль
дороги, прыжок, финальный край, прибытие.

**Критерий приёмки:** `leap.js` меньше 400 строк, петля проходится целиком,
поведение не изменилось ни в одном такте.

## Задача 2. Конвейер карты — одна команда

Сейчас портрет карты проходит путь: генерация в PixelLab → выбор кадра глазами
→ `design-system/card-art.py` руками → запись в манифест руками → запись в
`src/data/cards.js` руками. Каждый стык — минуты и место для ошибки.

Собрать `design-system/new-card.py`:

```
python3 design-system/new-card.py hermit --name "The Hermit" --numeral IX
```

Что делает:

1. берёт шаблон промпта из `docs/pixellab.md` и подставляет карту;
2. просит у генератора **сетку вариантов за один вызов**, а не один кадр;
3. складывает контактный лист `design-system/wip/<id>_grid.png` с номерами;
4. по выбору номера (`--pick 4`) прогоняет кадр через существующий
   `card-art.py` — инверсия, снап в палитру, кроп, чётные размеры, акцент;
5. кладёт результат в `public/assets/card/<id>_on_the_card.png`;
6. дописывает запись в манифест ассетов и заготовку карты в `cards.js`
   (id, numeral, name, minigame, пустые `reading`), ничего не затирая;
7. дописывает строку в `ASSETS.md`.

`РЕШИТЬ` — **общее зерно генерации.** У Башни зерно фиксировали вручную ради
единого стиля (`83a0c00`). Либо зерно живёт в конфиге конвейера одно на все
карты, либо у каждой карты своё в `cards.js`. Первое даёт единство, второе —
свободу; смешивать нельзя.

## Задача 3. Проверка стиля — скриптом, не глазами

«Несходимость стиля между картами» — одна из трёх названных статей расхода
времени. Она проверяема автоматически.

`design-system/check-assets.py` проходит по всем ассетам сборки и валит сборку,
если находит:

- цвет вне `tarot-journey.hex` (14 значений; исключение — `#232323` и `#A0A0A0`
  каменного тайлсета, решение 2026-08-27);
- полупрозрачный пиксель (альфа не 0 и не 255);
- нечётный размер по любой стороне;
- масштаб, не сводящийся к целому (генератор отдал нецелый апскейл).

Вешается на `npm run build` и на CI. Ассет, который не прошёл, не попадает в
игру — и сводить стиль руками больше не нужно.

## Задача 5. Хвост, который мешает уже сейчас

Три правки не из темы задания, но они блокируют показ игры людям:

1. Карта без своей сцены не попадает в раздачу вообще (сейчас выпадает и
   пропускает мини-игру — продукт читается как обычный ридер).
2. Тестовый режим **не выключать, а вынести за URL-параметр.** Алисе он нужен
   на телефоне: карты по кругу в порядке `DECK_ORDER`, чтобы знать, что за чем
   идёт. Но сейчас `SEQUENTIAL_DRAW = true` — константа в `cards.js`, и она
   уехала на прод: по обычной ссылке любой человек получает тестовый порядок.
   Сделать так:
   - `?seq=1` — карты по кругу, позиция в `localStorage` как сейчас;
   - `?card=<id>` — сразу конкретная карта, без прохода по кругу (экономит
     минуты на каждой проверке);
   - без параметров — случайная выдача из карт, у которых есть сцена.
   Константу `SEQUENTIAL_DRAW` убрать. Параметры читаются один раз при старте,
   в остальном код о них не знает.
3. Pixelify Sans самохостом рядом с `alagard.ttf` — сейчас это единственный
   рантайм-запрос в сеть, прямое нарушение §14, и он уже один раз отвалился
   в плейтесте №3.
